============================================================
  清源QMS  Windows 单机离线版 使用说明
============================================================

【这是什么】
清源QMS 品控全流程信息管理系统的单机演示版，已内置精简 Java
运行时、MariaDB 数据库、Redis 和系统本体。
不需要安装 Java/Python/数据库，不需要联网，Windows 10/11 (64位)
解压后双击即可使用。
v1.2.1 起为"桌面 App"形态：双击图标直接打开清源QMS窗口，
不再出现黑色控制台窗口，也不依赖外部浏览器。

------------------------------------------------------------
一、启动方法（重要：先完整解压！）
------------------------------------------------------------
1. 收到的是 清源QMS_单机版.zip，请先把整个 zip 解压到桌面或
   “文档”等普通文件夹（右键 → 全部解压）。
   切勿在压缩包预览窗口、微信/QQ 接收目录里直接双击运行，
   否则文件不完整，会启动失败。
2. 打开解压后的“清源QMS_单机版”文件夹，
   双击【清源QMS.exe】。
3. 会直接弹出“清源QMS 品控工作台”桌面窗口（没有黑窗）：
   - 首次启动需初始化本地数据库，约 30~60 秒；
   - 以后每次启动约 10~25 秒；
   - 窗口内会分段显示启动进度，完成后自动进入登录页，
     不需要再打开浏览器。
   - 首次成功启动后，桌面和开始菜单会自动生成
     “清源QMS”快捷方式，以后双击桌面图标即可。
4. 演示账号：admin / Qms@Demo2026
   （另有抽样员、检验员、复核员、质量管理员等演示角色账号，密码相同）
   演示账号仅供体验，正式使用请登录后尽快修改密码。
5. 极少数精简版 Windows 没有 WebView2 运行时（窗口内核），
   程序会弹出中文提示并给出下载安装引导，按提示安装一次即可。

------------------------------------------------------------
二、停止程序
------------------------------------------------------------
直接关闭“清源QMS”桌面窗口（右上角 ×）即可。
程序会先把缓存数据存盘、再干净关闭内置数据库，
随后数据库、缓存和服务全部停止，不进托盘、不开机自启、
后台不会有任何残留进程。
窗口右下角的“清源工具”可手动重启服务、打开日志/数据目录，
一般情况无需使用。

------------------------------------------------------------
三、数据说明（务必知悉）
------------------------------------------------------------
1. 本版本为【单机离线演示版】：账号、检验任务、报告、不合格案件、
   附件等全部数据保存在本文件夹的 data 目录中，不连接任何服务器。
2. 每台电脑的数据各自独立、互不相通、不会联网同步；
   复制整个文件夹到另一台电脑，数据会原样带走。
3. 删除整个文件夹即彻底删除全部数据。
4. 想恢复成“全新出厂”状态：先关闭程序，删除文件夹内的 data 目录，
   再双击启动，系统会自动重新建库并灌入初始演示数据。
5. 日志在 logs 目录，排查问题时可查看。
6. 请勿删除或改名 runtime、app、清源QMS.exe，否则无法启动。

------------------------------------------------------------
四、微信 / QQ 发送注意
------------------------------------------------------------
1. 必须发送【整个 zip 压缩包】，不要单独发 exe——微信、QQ 会直接
   拦截 .exe 文件（提示“文件存在安全风险”）。
2. 若 zip 也被拦截，可把文件改名加后缀（如 .zipx）发出，
   让对方下载后改回 .zip 再解压；或套一层文件夹重新压缩。
3. 浏览器/微信提示风险时，选择“保留/仍要接收”。

------------------------------------------------------------
五、杀毒软件误报与 SmartScreen
------------------------------------------------------------
本程序未做商业代码签名，360、火绒、腾讯电脑管家、Windows Defender
等可能误报（打包程序常见现象，非病毒）：
- 360/火绒/电脑管家：隔离区中“恢复/信任”，并把整个
  “清源QMS_单机版”文件夹加入信任区/白名单后重新双击；
- SmartScreen 蓝窗“已保护你的电脑”：点【更多信息】→【仍要运行】；
- Defender 删除了文件：Windows 安全中心 → 病毒和威胁防护 →
  保护历史记录中还原，并把该文件夹加入排除项。

------------------------------------------------------------
六、常见问题
------------------------------------------------------------
Q: 双击后没反应 / 窗口一闪而过 / 提示缺少运行文件？
A: 没有先解压、直接在 zip 里运行了。完整解压到普通文件夹后重试。

Q: 双击后弹出"需要 WebView2"的提示？
A: 你的 Windows 缺少窗口内核组件，按弹窗里的中文引导下载安装
   微软 WebView2 Runtime（一次性、约 1~2 分钟），装好后重新双击即可。

Q: 提示"端口 18080 已被占用"？
A: 本程序已在运行（任务栏找清源QMS 图标）；关闭原窗口再启动，
   必要时重启电脑。

Q: 窗口里白屏 / 转圈 / 提示网络问题？
A: 首次启动较慢，请等窗口进度走完；使用中若内置服务短暂无响应，
   看门狗会在约 1 分钟内自动重启恢复，页面会自动刷新。
   长时间不恢复时点右下角"清源工具 → 重启服务"。

Q: 启动失败弹窗怎么办？
A: 点弹窗或"清源工具 → 日志目录"查看 backend.log、mariadb.err，
   常见原因是文件夹被放在 C:\Program Files 等无写入权限的位置，
   请移动到桌面/文档后重试。

Q: 换了电脑数据还在吗？
A: 不在。各电脑数据独立；需要带走数据请复制整个文件夹。

Q: 首次启动被防火墙弹窗？
A: 本程序只监听 127.0.0.1（仅本机能访问），如出现防火墙提示，
   点“取消/拒绝”也不影响使用；允许专用网络亦可。

------------------------------------------------------------
七、技术信息（可忽略）
------------------------------------------------------------
- 内置：精简 JRE 17、MariaDB 10.11、Redis、Spring Boot 后端、
  React 前端（由后端同端口托管）；
- 界面：独立桌面窗口（pywebview + 系统 WebView2），
  无控制台黑窗、无托盘驻留、无开机自启；
- 本机端口：18080(系统) / 13306(内置数据库) / 16379(内置缓存)，
  均只绑定 127.0.0.1，不对外网开放，不影响电脑上已有的
  MySQL/Redis/其他业务系统；
- 运行期守护：每 10 秒真实业务探针巡检（SELECT 1 + 缓存 PING），
  约 30~45 秒无响应自动保存现场（logs\freeze-*）并重启恢复；
- 首次启动自动执行数据库迁移与演示数据初始化（Flyway）。
